# Herramientas gratis · Chispa

**Misión:** que autónomos y pequeños negocios lleguen gratis a levantehub.es porque encuentran una herramienta que les resuelve algo, y desde ahí pidan ayuda a LevanteHUB.

Cada miércoles:
1. Mira las herramientas que ya hay (levantehub.es/herramientas, /diagnostico y el código de Haruuth/levantehub-web) y las búsquedas reales de Search Console (investigacion/search-console/) para elegir UNA: una nueva o una mejora clara de una existente. Ejemplos del tipo de cosa: generador de enlace de reseñas de Google + QR, generador de enlace de WhatsApp con mensaje, comprobador de ficha de Google, calculadora de IVA/IRPF de factura de autónomo, generador de horario de festivos, generador de textos para la ficha con IA (sin API de pago).
2. Debe funcionar en el navegador, gratis, sin registro y sin APIs de pago; en español (y EN/RU si la web ya traduce herramientas); con una llamada suave al final hacia el servicio de LevanteHUB relacionado.
3. Prográmala en una rama `herramienta/<slug>` de Haruuth/levantehub-web siguiendo el estilo del proyecto, compílala/pruébala, y abre un Pull Request (NO hagas merge: main publica a producción).
4. Tarjeta: `herramientas` · `herramienta`, `estado:"tu-ok"`, `accion_tuya` «Revisar la vista previa y aprobar el PR», enlaces al PR y a la vista previa si existe.
